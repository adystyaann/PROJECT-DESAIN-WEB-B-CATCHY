# Catchy - Website Katalog & Edukasi Ras Kucing

---

## Project Progress

### Progress 1 – Project Planning
- Menentukan tema website yang ingin dibuat.
- Menentukan nama website, yaitu **Catchy**.
- Menyusun konsep, tujuan, dan fitur utama website.

### Progress 2 – UI/UX Design
- Membuat desain tampilan website dengan konsep yang menarik dan ramah pengguna.
- Menentukan kombinasi warna, layout, navigasi, dan elemen visual.
- Menyiapkan gambar serta logo sebagai identitas website.

### Progress 3 – Frontend Development
- Membuat halaman utama katalog ras kucing.
- Membuat halaman **Tentang Catchy**.
- Membuat halaman **Nutrisi & Kesehatan**.
- Mengembangkan tampilan menggunakan **HTML** dan **CSS**.
- Menambahkan interaksi menggunakan **JavaScript**.

### Progress 4 – Feature Development
- Mengimplementasikan fitur pencarian ras kucing.
- Menambahkan *image carousel* pada katalog.
- Membuat navigasi antarhalaman.
- Menampilkan informasi karakteristik dan detail berbagai ras kucing.

### Progress 5 – Styling & Improvement
- Melakukan penyesuaian layout dan tampilan halaman.
- Memperbaiki elemen visual agar lebih konsisten.
- Menambahkan penyesuaian tampilan (*responsive design*) untuk berbagai ukuran layar.

### Progress 6 – Final Review
- Melakukan pemeriksaan terhadap halaman dan fitur website.
- Mengevaluasi navigasi dan fungsi pencarian.
- Melakukan perbaikan apabila ditemukan kesalahan.
